# 🤖 简单聊天机器人

基于本地 Qwen2.5 模型的命令行聊天程序

## 🚀 快速开始

### 环境要求

- Python 3.8+
- 已安装 llama-cpp-python

### 运行

```bash
python main.py
```

启动后就可以开始聊天了！输入 `quit` 或 `exit` 退出。

## 💬 使用方法

1. 启动后，看到提示 `👤 你:` 就可以输入消息
2. 按回车发送，等待机器人回复
3. 输入 `quit`、`exit` 或 `退出` 结束对话
4. 按 `Ctrl+C` 也可以强制退出

## ✨ 特点

- **极简设计**：只保留核心对话功能
- **本地运行**：完全在本地执行，无需联网
- **多轮对话**：自动维护对话历史，支持上下文理解
- **正确模板**：使用 Qwen2.5 模型的官方聊天模板格式
